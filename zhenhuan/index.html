不再是换背景的立绘

正面、三分之二侧面、纯侧面、背面使用不同轮廓。头部、眼睑、瞳孔、眉弓、口型、肩肘腕、耳坠与衣袖均可独立控制。动作遵循预备、出势、停顿与收势，而非让所有人物始终摆动。

对白轨与摄影轨彼此独立。说话时可以切到听者反应，也可以跨越镜头保留同一句对白。过肩正反打保持对话轴线；细节插入、背面调度、俯拍水碗、低机位与焦点转移各承担不同叙事任务。

画面确实由 SVG 构成

宫殿、人物、面部、衣纹、饰物、水面、灯火与光影均为路径、渐变、图案或 SVG 滤镜。正片不嵌入原剧截图、演员照片、位图精灵或视频。仅在 MP4 导出阶段使用离屏 Canvas 将 SVG 帧转换为视频像素；完成后的 MP4 回放是独立视频。影片是原创矢量人物的风格化写实尝试，并非真人摄影或原剧画面的复刻。

便于拆解，也便于重做

导演台可逐帧、逐镜跳转，冻结摄影机、关闭景深、显示构图辅助线、导出本帧 SVG。角色试镜可切换人物、视角、情绪与手势。完整影片由同一时间轴计算，暂停与跳转不依赖 CSS 动画重新开始。

字幕和画面可离线运行；音景由 Web Audio 合成。中文朗读调用系统语音，品质、可用性与是否离线取决于设备；它不是演员配音。默认关闭音景与朗读，避免浏览器自动播放限制。

改编与科学边界

对白重新创作，次要调度及时间顺序适度压缩。保留告发、人证、亲审、初验、察水、复验、翻供、问罪与温沈余波。后续自伤只以文字交代，不描画过程。“滴血验亲”仅为剧情中的错误观念；血滴相融与分离都不能判断亲缘。

在导演台，逐帧以24帧网格定位，实时播放由浏览器 requestAnimationFrame 调度。关闭景深可以检查轮廓。冻结摄影机可以区分镜头运动与人物表演。试镜窗可独立查看四种视角、八种情绪与多种手势。

点击右上角「导出 MP4」，选择完整剧情、单幕、当前镜头、10 秒试导或自定义范围。支持 720p 至 4K、24 / 30 fps、画面字幕与可选 AAC 合成音景。优先逐帧编码；能力不足时明确切换原生 MP4 兼容录制。系统朗读不会写入视频。原 SVG 场景保留，视频仅是派生文件。

声音与性能

点击音景启用原创合成环境声、低音与动作音效。朗读依赖系统中文语音，可能没有可用声音；未配置中文声音时，字幕不受影响。快速跳镜、倍速或暂停会取消旧的朗读，避免叠音。

全屏 API 与系统语音因浏览器而异。矢量景深滤镜可能给低性能设备带来负担；关闭景深后，人物动作与分镜保持完整。进入试镜或说明会自动暂停正片。

改编范围

本片为《甄嬛传》相关事件的原创短剧改编，不是原剧逐字逐镜复刻。人物不追求演员肖像。采用风格化的写实比例与明暗塑造，但仍是可见笔触与路径的二维矢量表演。
